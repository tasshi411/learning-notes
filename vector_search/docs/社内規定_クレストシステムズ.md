# 株式会社クレスト・システムズ 社内規定集（抜粋版）

本書は、株式会社クレスト・システムズ（以下「当社」という）の就業に関する規定のうち、
従業員の日常業務で参照頻度の高い「出張規程」「休暇規程」「勤務制度」「経費精算規程」を抜粋したものである。

本書に記載のない事項は、就業規則本体（文書ID: HR-REG-2026-000）および各個別規程に従う。
記載内容に疑義がある場合は、人事総務本部 人事企画部（内線 3100 / hr-planning@crest-systems.example.jp）に照会すること。

---

## 第1章 総則

### 第1条（目的）

本規定は、当社従業員の出張、休暇、勤務形態および経費精算に関する取扱いを定め、
業務の円滑な遂行と従業員の適正な処遇を図ることを目的とする。

### 第2条（適用範囲）

1. 本規定は、当社に在籍するすべての正社員、契約社員および嘱託社員に適用する。
2. パートタイム従業員および派遣社員については、第4章（休暇規程）のうち第20条から第24条のみを適用し、
   その他の事項は「パートタイム就業規則」（文書ID: HR-REG-2026-010）による。
3. 出向者については、出向先の規定を優先的に適用する。ただし、日当および慶弔休暇については本規定を適用する。

### 第3条（用語の定義）

| 用語 | 定義 |
|---|---|
| 営業日 | 当社所定休日（土曜・日曜・国民の祝日・年末年始）を除く日 |
| 直属上長 | 従業員の勤怠および業務指示の一次承認権限を持つ管理職 |
| 部門長 | 部の長（部長職）。一次承認者の上位承認者 |
| 本部長 | 本部の長（執行役員相当）。最終承認者 |
| 管理職 | 課長職（グレードM1）以上の職位にある者 |
| 一般職 | グレードG1からG5に該当する者（管理職を除く） |

## 第2章 出張規程

### 第4条（出張の定義と区分）

1. 出張とは、勤務地から片道50km以上離れた場所、または通常の移動手段で片道2時間以上を要する場所へ、
   業務命令により赴くことをいう。
2. 出張は以下の3区分とする。
   - **日帰り出張**: 宿泊を伴わない出張
   - **国内出張**: 日本国内における宿泊を伴う出張
   - **海外出張**: 日本国外への出張（宿泊の有無を問わない）
3. 片道50km未満かつ片道2時間未満の外出は「近距離外出」として扱い、出張とはみなさない。
   近距離外出の交通費は、第30条（交通費精算）に従い実費精算とする。

### 第5条（出張の申請手続）

1. 出張を行う従業員は、出張管理システム「TRIP」より出張申請書を提出し、事前承認を得なければならない。
2. 申請期限は次のとおりとする。

   | 出張区分 | 申請期限 | 承認者 |
   |---|---|---|
   | 日帰り出張 | 出発日の3営業日前まで | 直属上長 |
   | 国内出張 | 出発日の5営業日前まで | 直属上長および部門長 |
   | 海外出張 | 出発日の20営業日前まで | 部門長および本部長 |

3. 出張費用の総額見積が30万円を超える場合は、区分にかかわらず本部長の承認を要する。
4. 緊急やむを得ない事由により事前申請ができない場合は、出張開始前に直属上長へ口頭または
   チャット（社内ツール「Crest Talk」）で連絡し、帰着後3営業日以内に事後申請を行うこと。
   事後申請は月2回を上限とし、これを超える場合は部門長が理由書を人事企画部へ提出する。

### 第6条（出張日当）

1. 出張者には、食事代および諸雑費の補填として日当を支給する。日当は領収書の提出を要しない。
2. 国内出張の日当は次のとおりとする（1泊あたり）。

   | 職位 | 国内出張 日当 |
   |---|---|
   | 役員 | 5,000円 |
   | 管理職 | 3,500円 |
   | 一般職 | 3,000円 |

3. 日帰り出張の日当は、職位にかかわらず一律 **1,500円** とする。
   ただし、移動を含む拘束時間が10時間を超える日帰り出張については **2,500円** とする。
4. 海外出張の日当は、渡航先を甲地域・乙地域に区分して次のとおりとする（1日あたり）。

   | 職位 | 甲地域 | 乙地域 |
   |---|---|---|
   | 役員 | 12,000円 | 9,000円 |
   | 管理職 | 8,500円 | 6,000円 |
   | 一般職 | 7,000円 | 5,000円 |

   - **甲地域**: 北米、西欧、シンガポール、香港、オーストラリア、UAE
   - **乙地域**: 甲地域以外のすべての国・地域

5. 海外出張の日当は、日本出国日および日本帰国日を含めて計算する。
   出国日および帰国日については、所定額の50%を支給する。
6. 出張先で会社が食事を提供した場合、または取引先等から食事の提供を受けた場合は、
   当該食事1回につき日当から500円（海外出張の場合は1,000円）を控除する。

### 第7条（宿泊費）

1. 宿泊費は実費精算とし、領収書（宛名は「株式会社クレスト・システムズ」）の提出を必須とする。
2. 1泊あたりの上限額は次のとおりとする。

   | 宿泊地 | 上限額（1泊・税込） |
   |---|---|
   | 東京23区、大阪市、名古屋市、横浜市 | 14,000円 |
   | 上記以外の国内 | 11,000円 |
   | 海外 甲地域 | 25,000円 |
   | 海外 乙地域 | 18,000円 |

3. 繁忙期・イベント開催等により上限額での宿泊施設の確保が困難な場合は、
   事前に部門長の承認を得ることで上限額の1.5倍まで認める。承認は「TRIP」上の特例申請から行う。
4. 親族宅等に宿泊し宿泊費が発生しない場合は、宿泊実費に代えて1泊あたり **3,000円** の
   宿泊補助を支給する。この場合、日当は通常どおり支給する。
5. 夜行バス、寝台列車、および22時以降に出発する深夜便の航空機を利用し、
   車中泊となった場合は宿泊費を支給しない。ただし日当は1泊分を支給する。

### 第8条（交通費）

1. 出張の交通費は、最も経済的かつ合理的な経路により算出した実費を支給する。
2. 鉄道の利用基準は次のとおりとする。
   - 新幹線および特急列車は、片道100km以上の移動において利用できる。
   - 指定席は全職位が利用できる。
   - グリーン車は、役員、または片道4時間以上の移動において本部長の承認を得た場合に限り利用できる。
3. 航空機の利用基準は次のとおりとする。
   - 原則としてエコノミークラスを利用する。
   - 飛行時間が8時間以上の海外出張については、管理職以上はプレミアムエコノミークラスを利用できる。
   - ビジネスクラスは役員に限り利用できる。
   - 航空券は原則として当社契約旅行代理店「クレストトラベルデスク」を通じて手配する。
     自己手配は、代理店経由より5,000円以上安価となる場合に限り認める（比較画面の保存を必須とする）。
4. 自家用車の使用は、公共交通機関では業務遂行が困難な場合に限り、事前承認のうえ認める。
   燃料費は走行距離1kmあたり **20円** として算出し、高速道路料金および駐車場料金は実費を支給する。
5. タクシーの利用は次のいずれかに該当する場合に認める。
   - 公共交通機関が運行していない時間帯（22時以降または6時前）
   - 重量物・機材を運搬する場合
   - 取引先訪問において時間的制約が大きい場合（直属上長の事前了解を要する）

### 第9条（出張中の休日および移動時間の取扱い）

1. 所定休日に移動のみを行った場合は、休日出勤とはみなさず、**休日移動手当 2,000円／日** を支給する。
2. 所定休日に実業務（会議、作業、顧客対応等）を行った場合は、休日出勤として取扱い、
   「就業規則」第45条（休日労働）に基づき割増賃金を支給する。この場合、休日移動手当は支給しない。
3. 移動時間は、原則として労働時間に算入しない。ただし、機材の監視・運搬等の業務命令を
   伴う移動については労働時間に算入する。

### 第10条（仮払金）

1. 出張費用の見積額が **50,000円以上** の場合、仮払金を申請することができる。
2. 仮払申請は出発日の3営業日前までに「TRIP」より行う。振込は出発日の前営業日となる。
3. 仮払金は帰着後の精算において清算する。残額が生じた場合は精算日から5営業日以内に
   指定口座へ返金すること。

### 第11条（出張費の精算）

1. 出張者は、帰着日の翌営業日から起算して **10営業日以内** に、経費精算システム「KEIHI」より
   出張精算を行わなければならない。
2. 精算期限を超過した申請は、当月の支給対象外とし、翌々月の給与支給日に精算する。
3. 領収書は原本をPDFまたは画像で「KEIHI」にアップロードする。原本の物理提出は不要であるが、
   精算完了後1年間は各自で保管すること。
4. 1件あたり5,000円未満の交通費については、領収書に代えて交通系ICカードの利用履歴で足りる。

### 第12条（出張の中止・変更）

1. 会社都合により出張が中止・変更となった場合、発生したキャンセル料および変更手数料は会社が負担する。
2. 従業員の私的事由により出張が中止となった場合、キャンセル料は本人負担とする。
   ただし、本人または同居家族の傷病、慶弔その他やむを得ない事由による場合は会社が負担する。
3. 天災、交通機関の運休、感染症の流行等の不可抗力による中止は、会社都合として取扱う。

### 第13条（マイレージ・ポイントの取扱い）

1. 出張に伴い付与された航空会社のマイレージおよびホテルのポイントは、個人に帰属するものとする。
2. ただし、マイレージ獲得を目的として経済的合理性を欠く経路・便を選択してはならない。
3. 個人のマイレージを利用して出張の航空券を手配した場合、当該区間の運賃は精算対象外とする。

### 第14条（海外出張の特則）

1. 海外出張者は、出発前に以下を完了しなければならない。
   - 海外旅行保険への加入（会社が一括して付保する。「TRIP」の申請をもって手続完了とする）
   - 渡航先の安全情報の確認および「海外渡航届」の総務部への提出
   - パスポートの残存有効期間の確認（帰国予定日から6か月以上を推奨）
2. 外務省の海外安全情報において「レベル2（不要不急の渡航は止めてください）」以上が
   発出されている地域への出張は、本部長および代表取締役の承認を要する。
3. 現地通貨の両替差損益は精算対象とし、精算レートは「帰国日の前営業日における
   三菱UFJ銀行の対顧客電信売買相場仲値（TTM）」を用いる。
4. 海外出張から帰着した従業員は、帰国日の翌日を休養日として取得できる。
   休養日は有給休暇の日数には算入しない。対象は飛行時間8時間以上の出張に限る。

## 第3章 勤務制度

### 第15条（所定労働時間）

1. 1日の所定労働時間は7時間45分とし、休憩時間は60分とする。
2. 標準勤務時間は9時00分から17時45分までとする。

### 第16条（フレックスタイム制）

1. 当社は全部門にフレックスタイム制を導入する。ただし、シフト勤務が必要な
   カスタマーサポート部およびデータセンター運用部を除く。
2. コアタイムは **11時00分から15時00分** とする。
3. フレキシブルタイムは、始業が7時00分から11時00分、終業が15時00分から22時00分の範囲とする。
4. 清算期間は1か月（毎月1日から末日まで）とし、清算期間における総労働時間は
   所定労働日数に7時間45分を乗じた時間とする。
5. コアタイムに遅刻または早退した場合、欠勤控除は行わないが、直属上長への事前連絡を要する。

### 第17条（リモートワーク）

1. リモートワークは原則として **週3日** を上限とする。
2. 毎週火曜日は全社出社日とし、リモートワークを認めない。
   ただし、出張、休暇、傷病その他やむを得ない事由がある場合はこの限りでない。
3. 入社後3か月間は原則として全日出社とする。
4. リモートワーク手当として、月額 **4,000円** を支給する。月間のリモート勤務日数が
   4日未満の月は支給しない。
5. リモートワーク時の通信費・光熱費は前項の手当に含まれるものとし、別途精算はしない。
6. リモートワーク中の勤務場所は、本人の自宅または会社が承認したサテライトオフィスに限る。
   カフェ等の公共空間での機密情報の取扱いは「情報セキュリティ規程」（文書ID: IS-REG-2025-003）
   第12条により禁止する。

## 第4章 休暇規程

### 第18条（年次有給休暇の付与日数）

1. 6か月間継続勤務し、全労働日の8割以上出勤した従業員に対し、10日の年次有給休暇を付与する。
2. 以降の付与日数は次のとおりとする。

   | 継続勤務年数 | 付与日数 |
   |---|---|
   | 6か月 | 10日 |
   | 1年6か月 | 11日 |
   | 2年6か月 | 12日 |
   | 3年6か月 | 14日 |
   | 4年6か月 | 16日 |
   | 5年6か月 | 18日 |
   | 6年6か月以上 | 20日 |

3. 当社は法定日数に加え、入社日に **5日** の特別付与を行う。この5日は入社日から利用でき、
   入社後1年を経過した時点で未使用分は消滅する（繰越不可）。

### 第19条（年次有給休暇の繰越および時効）

1. 未使用の年次有給休暇は翌年度に限り繰り越すことができる。
2. 繰越を含む年次有給休暇の保有上限は **40日** とする。
3. 繰越期間を経過した年次有給休暇は消滅する。消滅分の買い取りは行わない。
4. 退職時の未使用有給休暇の買い取りも行わない。

### 第20条（年次有給休暇の申請手続）

1. 年次有給休暇の取得を希望する者は、勤怠システム「ATTEND」より申請し、直属上長の承認を得る。
2. 申請期限は次のとおりとする。

   | 取得日数 | 申請期限 |
   |---|---|
   | 1日以内（半日・時間単位を含む） | 取得日の3営業日前まで |
   | 連続2日から4日 | 取得日の5営業日前まで |
   | 連続5日以上 | 取得初日の2週間前まで |

3. 傷病その他の緊急事由により事前申請ができない場合は、**当日の始業時刻から30分以内**（フレックス
   勤務者は10時00分まで）に直属上長へ電話または「Crest Talk」で連絡し、
   出社後3営業日以内に事後申請を行うこと。
4. 会社は、事業の正常な運営を妨げる場合に限り、他の時季に変更することを求めることができる（時季変更権）。
   時季変更を行う場合は、申請者に対し理由を書面で通知する。

### 第21条（半日単位・時間単位の年次有給休暇）

1. 半日単位の年次有給休暇を取得できる。区分は次のとおりとする。
   - 午前半休: 9時00分から13時00分
   - 午後半休: 13時00分から17時45分
2. 時間単位の年次有給休暇は、1年度あたり **5日分（38時間45分）** を上限として取得できる。
   取得は1時間単位とする。
3. 時間単位年休は、繰り越した有給休暇からは取得できず、当年度付与分からのみ取得できる。

### 第22条（年5日の取得義務）

1. 年次有給休暇を10日以上付与された従業員は、付与日から1年以内に **5日以上** を取得しなければならない。
2. 付与日から9か月を経過した時点で取得日数が3日に満たない従業員に対しては、
   会社が時季を指定して取得させることがある。
3. 部門長は、四半期ごとに部下の取得状況を確認し、人事企画部へ報告する。

### 第23条（特別休暇）

1. 次の事由に該当する場合、有給の特別休暇を付与する。

   | 事由 | 日数 |
   |---|---|
   | 本人の結婚 | 5日 |
   | 子の結婚 | 2日 |
   | 配偶者の出産 | 3日 |
   | 配偶者、父母、子の死亡 | 10日 |
   | 祖父母、兄弟姉妹、配偶者の父母の死亡 | 3日 |
   | 伯叔父母、孫、配偶者の祖父母・兄弟姉妹の死亡 | 1日 |
   | 裁判員・証人としての出頭 | 必要日数 |
   | 天災・公共交通機関の途絶による出勤困難 | 必要日数 |

2. 本人の結婚に伴う特別休暇は、入籍日または挙式日のいずれか早い日から **1年以内** に取得すること。
   分割取得を認める。
3. 忌引休暇は、死亡日または死亡の翌日から起算して連続して取得することを原則とする。
   遠隔地（片道500km以上）での葬儀に参列する場合は、1日を加算する。
4. 慶弔に伴う祝金・見舞金については、本規定では定めず「福利厚生規程」
   （文書ID: HR-REG-2026-020）第8条から第11条による。

### 第24条（夏季休暇・年末年始休暇）

1. 夏季休暇として **3日** を付与する。取得期間は **7月1日から9月30日** までとする。
2. 夏季休暇は年度をまたいで繰り越すことはできない。
3. 年末年始休暇は12月29日から1月3日までとし、所定休日として扱う（休暇日数には算入しない）。

### 第25条（リフレッシュ休暇）

1. 勤続年数が次の節目に達した従業員に対し、リフレッシュ休暇を付与する。

   | 勤続年数 | 付与日数 | special_bonus |
   |---|---|---|
   | 5年 | 5日 | 50,000円 |
   | 10年 | 10日 | 100,000円 |
   | 20年 | 15日 | 200,000円 |

2. リフレッシュ休暇は該当日から **2年以内** に取得すること。連続取得を推奨するが、分割も可能とする。
3. 表中の special_bonus は旅行補助金であり、支給月の給与と併せて支給する（課税対象）。

### 第26条（病気休暇）

1. 私傷病により就業できない場合、年度あたり **5日** を上限として有給の病気休暇を取得できる。
2. 連続3日以上の病気休暇を取得する場合は、医師の診断書の提出を求める。
   診断書の取得費用は、5,000円を上限として会社が負担する。
3. 病気休暇を使い切った後の私傷病による欠勤は、年次有給休暇を充当するか、
   または無給の欠勤として扱う。
4. 私傷病による欠勤が連続30日を超える場合は「休職規程」（文書ID: HR-REG-2026-030）による。

### 第27条（子の看護休暇・介護休暇）

1. 小学校就学前の子を養育する従業員は、子の看護休暇を取得できる。
   - 対象の子が1人の場合: 年5日
   - 対象の子が2人以上の場合: 年10日
2. 要介護状態にある対象家族を介護する従業員は、介護休暇を取得できる。日数は前項と同様とする。
3. 子の看護休暇および介護休暇は、当社においては **有給** とする（法定を上回る措置）。
4. 取得は1時間単位で可能とする。

### 第28条（産前産後休業・育児休業・介護休業）

1. 産前休業は出産予定日の6週間前（多胎妊娠の場合は14週間前）から、
   産後休業は出産日の翌日から8週間とする。
2. 育児休業は、原則として子が1歳に達する日まで取得できる。
   保育所に入所できない等の事情がある場合は、最長で子が2歳に達する日まで延長できる。
3. 当社は法定に上乗せし、育児休業開始から **最初の10営業日** を有給とする。
4. 介護休業は、対象家族1人につき通算93日まで、3回を上限として分割取得できる。
5. 詳細な手続および給付金については「育児・介護休業規程」（文書ID: HR-REG-2026-040）による。

### 第29条（休暇取得時の業務引継）

1. 連続3営業日以上の休暇を取得する場合、事前に業務引継書を作成し、直属上長および代行者に共有する。
2. 引継書には、進行中の案件、想定される問合せ、緊急連絡の要否を記載する。
3. 休暇中の従業員への業務連絡は、緊急時を除き行わない。緊急時の判断は部門長が行う。

## 第5章 経費精算規程

### 第30条（交通費精算）

1. 通勤以外の業務上の交通費は、実費を精算する。
2. 精算は「KEIHI」より、**発生月の翌月10営業日以内** に申請する。
3. 通勤定期券の区間内の移動については、交通費を支給しない。

### 第31条（会議費・交際費）

1. 社内会議に伴う飲食費（会議費）は、参加者1人あたり **3,000円** を上限とする。
2. 取引先等との会食（交際費）は、参加者1人あたり **10,000円** を上限とし、
   実施前に部門長の承認を要する。1人あたり10,000円を超える場合は本部長の承認を要する。
3. 交際費の精算時には、参加者全員の氏名・所属・目的を「KEIHI」の備考欄に記載すること。

### 第32条（自己啓発支援）

1. 業務に関連する書籍の購入費は、月額 **10,000円** を上限として会社が負担する。
   購入した書籍は原則として部門の共有資産とする。
2. 業務に関連する資格の受験料は、**合格した場合に限り** 全額を補助する。不合格時は補助しない。
   ただし、会社が受験を命じた資格については合否にかかわらず全額を会社が負担する。
3. 外部セミナー・カンファレンスへの参加費は、年間 **150,000円** を上限として会社が負担する。
   参加後2週間以内に社内向けの共有レポートを提出すること。
4. 海外カンファレンスへの参加は、渡航費を含め第2章（出張規程）の基準を適用する。

## 第6章 よくある質問（FAQ）

### Q1. 日帰り出張でも日当はもらえますか？

はい。日帰り出張の日当は職位にかかわらず一律1,500円です。
ただし移動を含む拘束時間が10時間を超える場合は2,500円となります（第6条第3項）。

### Q2. 東京への出張でホテルが14,000円で見つかりません。どうすればよいですか？

事前に部門長の承認を得ることで、上限額の1.5倍（東京23区の場合は21,000円）まで認められます。
「TRIP」の特例申請から手続きしてください（第7条第3項）。

### Q3. 出張の精算をうっかり忘れて12営業日経ってしまいました。

精算期限（帰着日の翌営業日から10営業日以内）を超過した申請は当月の支給対象外となり、
翌々月の給与支給日での精算となります。支給自体が取り消されることはありません（第11条第2項）。

### Q4. 当日の朝に発熱しました。有給休暇はどう申請すればよいですか？

始業時刻から30分以内（フレックス勤務者は10時00分まで）に直属上長へ連絡し、
出社後3営業日以内に「ATTEND」で事後申請してください（第20条第3項）。
なお、私傷病の場合は年次有給休暇ではなく病気休暇（年5日・有給）も利用できます（第26条）。

### Q5. 有給休暇を1時間だけ使いたいのですが可能ですか？

可能です。時間単位年休は年5日分（38時間45分）を上限に1時間単位で取得できます。
ただし前年度から繰り越した有給休暇からは取得できず、当年度付与分からのみとなります（第21条）。

### Q6. 結婚しました。特別休暇はいつまでに取ればよいですか？

入籍日または挙式日のいずれか早い日から1年以内です。5日間を分割して取得することもできます（第23条第2項）。

### Q7. リモートワークは何日までできますか？

週3日までです。ただし毎週火曜日は全社出社日のためリモートワークはできません。
また入社後3か月間は原則として全日出社となります（第17条）。

### Q8. 海外出張の翌日は休めますか？

飛行時間8時間以上の海外出張であれば、帰国日の翌日を休養日として取得できます。
この休養日は有給休暇の日数には算入されません（第14条第4項）。

### Q9. 自家用車で出張した場合のガソリン代はどう計算しますか？

走行距離1kmあたり20円で算出します。高速道路料金と駐車場料金は実費精算です。
なお自家用車の使用には事前承認が必要です（第8条第4項）。

### Q10. 退職時に余った有給休暇は買い取ってもらえますか？

買い取りは行っていません。消滅分・退職時残日数のいずれも買い取り対象外です（第19条第3項・第4項）。
